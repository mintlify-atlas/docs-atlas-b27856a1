Aether Sync is a pure-Python distributed state synchronization engine built for networks that fail. By combining a CRDT Last-Write-Wins store, ACK-based reliability, and periodic gossip, every node in a cluster converges to the same state — even with 30%+ packet loss and no central coordinator.

## How It Works

Aether Sync uses a four-layer stack to deliver reliable, eventually-consistent state across nodes:

<Steps>
  <Step title="Transport Layer">
    Raw UDP sockets carry JSON-serialized messages between nodes. Configurable packet-loss simulation lets you test chaos conditions locally.
  </Step>
  <Step title="Reliability Layer">
    Sequence numbers and ACK acknowledgments track every in-flight message. Unacknowledged messages are retried every 2 seconds.
  </Step>
  <Step title="Gossip Layer">
    Every node broadcasts its full state to all known peers on a configurable interval (default 3 seconds), healing any divergence automatically.
  </Step>
  <Step title="Store Layer">
    A CRDT Last-Write-Wins dictionary resolves write conflicts deterministically using physical timestamps and node IDs — no coordination required.
  </Step>
</Steps>

## Key Features

<CardGroup cols={2}>
  <Card title="CRDT Conflict Resolution" icon="shuffle">
    Deterministic Last-Write-Wins semantics. Timestamp ties broken by node ID for commutative, idempotent merges.
  </Card>
  <Card title="Multi-Master Writes" icon="arrows-left-right">
    Every node accepts reads and writes simultaneously. No primary/replica distinction.
  </Card>
  <Card title="Chaos-Resilient by Design" icon="bolt">
    Built-in network fault simulation. Designed to converge despite 30%+ packet loss.
  </Card>
  <Card title="Zero Dependencies" icon="feather">
    Pure Python using only the standard library: `socket`, `threading`, `json`, `random`.
  </Card>
</CardGroup>
